# GTA-Online-Dashboard
# 🎮 GTA Online | Vehicle Dashboard

**Projet de Data Visualisation — Microsoft Power BI**

Analyse comparative des véhicules de GTA Online à travers un tableau de bord présentant leurs caractéristiques, leurs prix et leurs performances.

---

## 📊 Vue d'ensemble

| Indicateur | Résultat |
|:---|---:|
| 🚗 Véhicules analysés | **795** |
| 💰 Prix moyen | **1,09 M GTA$** |
| 🎯 Véhicules armés | **131** |
| ⏱️ Meilleur temps au tour | **30,82 s** |

## 🎯 Objectif du projet

L'objectif est d'explorer les données des véhicules de **GTA Online**, développé par Rockstar Games, afin d'identifier les différences entre les catégories, de comparer les prix et d'étudier certaines caractéristiques des véhicules.

## 🗂️ Données analysées

Le jeu de données comprend **795 véhicules**. Les principales variables exploitées sont :

| Variable | Description |
|:---|:---|
| Marque et modèle | Identification du véhicule |
| Catégorie | Type de véhicule |
| Prix (GTA$) | Prix en monnaie virtuelle |
| Véhicule armé | Présence ou absence d'armement |
| Temps au tour | Performance exprimée en secondes |

## 📈 Visualisations

Le tableau de bord comprend quatre analyses principales :

1. **Répartition par catégorie** — Les 10 catégories les plus représentées.
2. **Top 10 des véhicules les plus chers** — Comparaison des prix maximums.
3. **Répartition des véhicules armés** — Comparaison entre véhicules armés et non armés.
4. **Top 10 des catégories les plus chères** — Classement selon le prix moyen.

## 🛠️ Outils et méthodologie

**Outil :** Microsoft Power BI Desktop

**Travail réalisé :**
- Importation et préparation des données.
- Création de colonnes calculées avec DAX.
- Construction d'indicateurs et de graphiques.
- Mise en forme d'un dashboard inspiré de l'univers GTA Online.
